# 🚗 Used Cars Data Analysis (2015–2024)

A data analytics project that cleans and visualizes used car listings in India.

---

## 📁 Files
- `DataCleaning.ipynb` — Data cleaning steps
- `Visualization.ipynb` — All charts and graphs
- `used_cars_cleaned.csv` — Cleaned dataset
- `used_cars_2015_2024.csv` — Filtered dataset (2015–2024)

---

## 📊 Dataset
- **9,570 rows** and **11 columns**
- Year range: **2015 to 2024**
- Columns: Brand, Model, Year, Age, KM Driven, Transmission, Owner, Fuel Type, Price

---

## 📈 Visualizations
1. Price Distribution
2. Top 10 Brands by Count
3. KM Driven vs Price
4. Year-wise Listings
5. Owner Type Analysis
6. Fuel Type Breakdown
7. Transmission Split
8. Average Price by Brand
9. Price vs Age
10. Correlation Heatmap
